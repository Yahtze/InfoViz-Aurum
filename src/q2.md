# Q2: Clean Sources of Electricity Generation by Country, Share and Mix, 2024

**Question:** How do countries compare in their clean electricity share in 2024, which have the highest and lowest shares, and what is each country's electricity generation mix made of?

## The Short Answer

Clean electricity in 2024 is very unevenly spread. Of the ${q2Facts.known} countries with a known clean share, ${q2Facts.high} generate at least 90% of their electricity from clean sources and ${q2Facts.low} generate 10% or less. Regions differ sharply: the median clean share is ${q2Facts.bestContinent.pct}% in ${q2Facts.bestContinent.name} and ${q2Facts.worstContinent.pct}% in ${q2Facts.worstContinent.name}. ${q2Facts.topSource} is the largest source in ${q2Facts.topCount} of the 10 highest shares, and in ${q2Facts.lowFossil} of the 10 lowest a fossil fuel is the largest source.

## How to Read This Page

The three plots answer the question in order, each one raising the next.

1. **[Where Is Clean Power?](#clean-share-map)** The map shows every country's 2024 clean share, so regional patterns appear first.
2. **[Who Is at the Extremes?](#highest-and-lowest-shares)** The rankings name the countries with the highest and lowest shares and give exact values.
3. **[What Are They Made Of?](#electricity-mix-by-country)** The donuts show the mix behind a share, so you can see which sources lie behind the extremes. Start with the default selection, then add countries you spotted on the map.

```js
// Facts Quoted in the Page Text, Computed from the Data so the Numbers Cannot Drift from the Charts
const q2Facts = (() => {
  const labels = {coal: "Coal", gas: "Gas", oil: "Oil", nuclear: "Nuclear", hydro: "Hydro", solar: "Solar", wind: "Wind", bioenergy: "Bioenergy", other_renewables_excluding_bioenergy: "Other Renewables"};
  const leader = (d) => d3.greatest(Object.keys(labels), (s) => +d[`${s}_share_pct`] || 0);
  const known = snapshot.filter((d) => d.cleanShare != null);
  const byShare = known.slice().sort((a, b) => d3.descending(a.cleanShare, b.cleanShare) || d3.ascending(a.country, b.country));
  const top = byShare.slice(0, 10);
  const bottom = byShare.slice(-10);

  const topCounts = d3.rollups(top, (v) => v.length, leader).sort((a, b) => d3.descending(a[1], b[1]));

  // Median Share per Continent (Only Continents with at Least Five Countries Count)
  const medians = d3.rollups(known.filter((d) => continentOf.has(d.country)), (v) => d3.median(v, (d) => d.cleanShare), (d) => continentOf.get(d.country))
    .map(([name, pct]) => ({name, pct: Math.round(pct)}))
    .sort((a, b) => d3.descending(a.pct, b.pct));

  return {
    known: known.length,
    high: known.filter((d) => d.cleanShare >= 90).length,
    low: known.filter((d) => d.cleanShare <= 10).length,
    topSource: labels[topCounts[0][0]],
    topCount: topCounts[0][1],
    lowFossil: bottom.filter((d) => ["coal", "gas", "oil"].includes(leader(d))).length,
    bestContinent: medians[0],
    worstContinent: medians.at(-1)
  };
})();
```

## Clean Share Map

Each country is shaded by its clean share of electricity generation in 2024. We chose a choropleth because the question is about comparing countries, and a map shows geographic patterns, such as clusters of high or low shares in a region, that a list cannot. Shares run from 0 to 100%, so a single sequential color scale from light to dark reads as low to high. Countries with no data get a grey hatch pattern, so they are not mistaken for a low share.

**Note:** We adjusted the standard YlGnBu color scale. It starts 15% of the way along the ramp instead of at its near-white end, so a 0% share stays visible against the white page. The shades are therefore slightly darker than the unadjusted scale at every value, but the scale is still linear from 0 to 100%.

## Electricity Mix by Country

<p class="bridge">The extremes raise a question a share cannot answer, which is what the electricity is actually made of.</p>

The map and rankings show only the clean share. This section shows what the rest of each country's electricity is made of in 2024: one donut per selected country, split into the three fossil sources (coal, gas, and oil) and the six clean sources (wind, solar, hydro, nuclear, bioenergy, and other renewables). We chose donuts because the question is about parts of a whole, and one small donut per country lets mixes be compared side by side. The donut hole shows the clean share. Slices follow the same order in every donut, with fossil sources first and clean sources after, so the clean part always lies on the same side. Angles are harder to compare than bar lengths, so exact values are available on hover, and slices under 5% are left unlabeled.

    .attr("aria-pressed", function () { return String(this.dataset.source === mixState.pinned); });
}

// Legend Across the Top, One Row for Fossil and One for Clean (Hover to Highlight, Click or Press Enter to Pin)
const mixLegend = mixSvg.append("g").attr("transform", `translate(${mixDims.marginLeft}, 50)`);

for (const [rowIndex, group] of ["Fossil", "Clean"].entries()) {
  const row = mixLegend.append("g").attr("transform", `translate(0, ${rowIndex * 26})`);
  row.append("text").attr("y", 10).attr("font-weight", 600).text(`${group}:`);
  mixSources.filter((s) => s.group === group).forEach((s, i) => {
    const item = row.append("g")
      .attr("class", "legend-item")
      .attr("data-source", s.name)
      .attr("transform", `translate(${60 + i * 120}, 0)`)
      .attr("tabindex", 0)
      .attr("role", "button")
      .attr("aria-label", `Highlight ${s.name}`)
      .on("mouseenter focus", () => mixHighlight(s.name))
      .on("mouseleave blur", () => mixHighlight(null))
      .on("click", () => {
        mixState.pinned = mixState.pinned === s.name ? null : s.name;
        mixHighlight(s.name);
      })
      .on("keydown", (event) => {
        if (event.key === "Enter" || event.key === " ") {
          event.preventDefault();
          mixState.pinned = mixState.pinned === s.name ? null : s.name;
          mixHighlight(s.name);
        }
      });
    item.append("rect").attr("class", "legend-hit").attr("x", -4).attr("y", -4).attr("width", 112).attr("height", 20).attr("rx", 4);
    item.append("rect").attr("width", 12).attr("height", 12).attr("fill", s.color);
    item.append("text").attr("x", 18).attr("y", 10).text(s.name);
  });
}

if (mixChosen.length === 0) {
  mixSvg.append("text")
    .attr("x", mixTotalWidth / 2)
    .attr("y", mixDims.marginTop + 60)
    .attr("text-anchor", "middle")
    .attr("font-size", 14)
    .attr("opacity", 0.6)
    .text("Select at least one country to draw its mix.");
}

mixChosen.forEach((name, i) => {
  const d = mixByName.get(name);
  const cx = mixDims.marginLeft + (i % mixDims.columns) * mixDims.cellWidth + mixDims.cellWidth / 2;
  const cy = mixDims.marginTop + Math.floor(i / mixDims.columns) * mixDims.cellHeight + mixDims.outerRadius + 4;
  const slices = mixPie(mixSources.map((s) => ({source: s, share: +d[`${s.key}_share_pct`] || 0, twh: +d[`${s.key}_twh`] || 0})));

  const donut = mixSvg.append("g").attr("transform", `translate(${cx}, ${cy})`);

  const arcs = donut.selectAll("g")
    .data(slices.filter((a) => a.data.share > 0))
    .join("g")
    .attr("class", "mix-slice highlightable")
    .attr("data-source", (a) => a.data.source.name);

  arcs.append("path")
    .attr("d", mixArc)
    .attr("fill", (a) => a.data.source.color)
    .attr("stroke", "#ffffff")
    .attr("stroke-width", 1)
    .append("title")
    .text((a) => `${name}\n${a.data.source.name}: ${mixPct(a.data.share)}% (${d3.format(",.1f")(a.data.twh)} TWh)`);

  arcs.filter((a) => a.data.share >= 5)
    .append("text")
    .attr("transform", (a) => `translate(${mixArc.centroid(a)})`)
    .attr("text-anchor", "middle")
    .attr("dy", "0.35em")
    .attr("font-size", 10)
    .attr("fill", (a) => labelFill(a.data.source.color))
    .attr("pointer-events", "none")
    .text((a) => `${Math.round(a.data.share)}%`);

  // Donut Hole: the Clean Share
  donut.append("text")
    .attr("text-anchor", "middle")
    .attr("font-size", 18)
    .attr("font-weight", 700)
    .attr("dy", "-0.1em")
    .text(`${mixPct(d.cleanShare)}%`);

  donut.append("text")
    .attr("text-anchor", "middle")
    .attr("font-size", 10)
    .attr("opacity", 0.7)
    .attr("dy", "1.3em")
    .text("Clean");

  // Country Name and Total Generation
  donut.append("text")
    .attr("y", mixDims.outerRadius + 20)
    .attr("text-anchor", "middle")
    .attr("font-size", 12)
    .attr("font-weight", 600)
    .text(name);

  donut.append("text")
    .attr("y", mixDims.outerRadius + 34)
    .attr("text-anchor", "middle")
    .attr("font-size", 10)
    .attr("opacity", 0.7)
    .text(`${d3.format(",.1f")(d.generationTwh)} TWh Generated`);
});

// Restore a Pinned Highlight after a Redraw
mixHighlight(null);

mixPanel.setChart(mixSvg.node());

## Comparison of the Visualizations

| | Clean Share Map | Highest and Lowest Shares | Electricity Mix by Country |
|---|---|---|---|
| **Shows** | Every country's clean share, as a color on a map | The countries with the highest and lowest clean shares, as bar lengths | What each selected country's electricity is made of, as slices of a donut |
| **Strengths** | Geographic patterns are visible, such as clusters of high or low shares in a region, and every country appears at once. | Exact values are easy to compare on a shared 0–100% axis, and the two extremes sit side by side, including places too small to see on the map. | The full mix is visible, not just the clean share, and countries can be compared side by side with the same source order in every donut. |
| **Weaknesses** | Color is hard to read precisely, and small countries are barely visible. Eight places cannot be drawn at all. | Only the extremes are shown, so the middle of the distribution and any geographic pattern are hidden, and the mix behind each share is not shown. | Angles are harder to compare than bar lengths, so exact shares need hover, and only a few countries fit on screen at once. |
| **Best For** | Spotting regional patterns in clean share | Looking up and comparing exact shares at the top and bottom | Understanding what a country's clean and fossil electricity consists of |
