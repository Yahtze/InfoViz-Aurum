# Q5: Clean Share Versus Fossil Generation, 2000–2024

Which countries increased their clean share while also reducing fossil-fuel generation, and which increased their clean share but still generated more?
Each mark is one of the 108 compared countries: its change in clean share (percentage points) across, and its change in fossil generation (TWh) up.
The right chart enlarges the band within ±60 TWh, where most countries overlap near zero.
Click a mark, or pick a country from the list, to trace that country over time in the charts below.

```js
// Create the Full Screen Panels Once, so Changing the Country Redraws the Charts Without Leaving Full Screen
import {fullscreenPanel} from "./components/fullscreen.js";

const panel = fullscreenPanel();
display(panel.element);
```

```js
// Load the Comparison Table (One Row per Compared Country) and the Country-by-Year Table
const comparison = await FileAttachment("data/comparison_2000_2024.csv").csv({typed: true});
const countryYear = await FileAttachment("data/country_year.csv").csv({typed: true});
```

```js
// Outcomes in Legend Order; Color and Shape Both Show the Outcome
const outcomes = [
  {key: "share_up_fossil_down", label: "Clean Share Up, Fossil Down", color: "#247f78", symbol: d3.symbolCircle},
  {key: "share_up_fossil_up", label: "Clean Share Up, Fossil Up", color: "#b8654a", symbol: d3.symbolTriangle},
  {key: "share_up_fossil_flat", label: "Clean Share Up, Fossil Unchanged", color: "#5f5f5f", symbol: d3.symbolDiamond},
  {key: "share_not_up", label: "Clean Share Not Up", color: "#a3a3a3", symbol: d3.symbolSquare}
];
const outcomeOf = new Map(outcomes.map((o) => [o.key, o]));
const countOf = (key) => comparison.filter((d) => d.outcome === key).length;

// The Enlarged Band Around Zero Fossil Change
const band = 60;

// Default Country: the Largest 2024 Generator Among "Share Up, Fossil Up" Countries Inside the Band
const example = comparison
  .filter((d) => d.outcome === "share_up_fossil_up" && Math.abs(d.d_fossil_twh) <= band)
  .sort((a, b) => d3.descending(a.generation_twh_2024, b.generation_twh_2024) || d3.ascending(a.country, b.country))[0];
```


## Selected Country Over Time

The left chart traces the selected country's clean share (its change is the mark's position across).
The right chart traces its fossil and clean generation (the change in fossil generation is the mark's height).

## What the Charts Show

```js
// Counts Used in the Text Below
const shareUp = comparison.filter((d) => d.d_clean_share_pp > 0);
const fossilDown = shareUp.filter((d) => d.d_fossil_twh < 0);
const fossilUp = shareUp.filter((d) => d.d_fossil_twh > 0);
```

Of the ${shareUp.length} countries whose clean share rose, ${fossilDown.length} cut fossil generation (lower right) and ${fossilUp.length} (${(100 * fossilUp.length / shareUp.length).toFixed(1)}%) still generated more fossil electricity in 2024 than in 2000 (upper right).
A rising clean share is therefore not enough on its own to tell whether fossil generation fell.
The largest increases are far outside the band: China's fossil generation grew by ${d3.format(",.0f")(comparison.find((d) => d.country === "China").d_fossil_twh)} TWh even as its clean share rose by ${comparison.find((d) => d.country === "China").d_clean_share_pp.toFixed(1)} points.
