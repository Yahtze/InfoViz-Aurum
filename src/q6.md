# Q6: Demand Growth and the Starting Mix, 2000–2024

How do electricity demand growth and the initial mix in 2000 differ between countries that reduced fossil-fuel generation and those that did not?
Each chart has one box per group (the middle half of the countries, with a thick line at the median) and every country as a mark.
The top chart shows demand growth from 2000 to 2024; the four below show each source's share of generation in 2000.
Hover a mark to highlight that country in all five charts. Pick a matched pair to ring two countries with similar demand growth but opposite fossil outcomes, and to compare them in the chart below.

```js
// Load the Comparison Table and Leave Out Countries with no Fossil Generation in Either Year (Nothing to Cut)
// The Country-by-Year Table Gives the Selected Pair's Generation in 2000 and 2024
const comparison = await FileAttachment("data/comparison_2000_2024.csv").csv({typed: true});
const countryYear = await FileAttachment("data/country_year.csv").csv({typed: true});

const noFossil = comparison.filter((d) => d.fossil_twh_2000 === 0 && d.fossil_twh_2024 === 0);
const countries = comparison
  .filter((d) => !noFossil.includes(d))
  .map((d) => ({...d, fell: d.d_fossil_twh < 0, demandRatio: d.demand_twh_2024 / d.demand_twh_2000}));

// The Two Groups, Fell First
const groups = [
  {key: true, label: "Fell", color: "#247f78", symbol: d3.symbolCircle},
  {key: false, label: "Did Not Fall", color: "#b8654a", symbol: d3.symbolTriangle}
];
const groupOf = (d) => groups.find((g) => g.key === d.fell);
const sizeOf = (g) => countries.filter((d) => d.fell === g.key).length;
```

```js
// Matched Pairs: for Each Country Whose Fossil Generation Fell, the Country with the Closest Demand Growth
// Whose Fossil Generation Did not Fall. Smallest Gaps First, Each Country Used Once, Ties by Name.
const candidates = [];
for (const a of countries.filter((d) => d.fell)) {
  for (const b of countries.filter((d) => !d.fell)) {
    candidates.push({fell: a, other: b, gap: Math.abs(a.demand_growth_pct - b.demand_growth_pct)});
  }
}
candidates.sort((p, q) => d3.ascending(p.gap, q.gap) || d3.ascending(p.fell.country, q.fell.country) || d3.ascending(p.other.country, q.other.country));

const pairs = [];
const used = new Set();
for (const c of candidates) {
  if (used.has(c.fell.country) || used.has(c.other.country)) continue;
  used.add(c.fell.country);
  used.add(c.other.country);
  pairs.push(c);
  if (pairs.length === 6) break;
}
```

## Inside a Matched Pair

The left bars show each country's mix in 2000. The right bars show how much its generation, clean generation, and fossil generation changed from 2000 to 2024, as a percentage of its 2000 generation (labels give the TWh).
Clean change + fossil change = generation change, so fossil generation fell only where clean generation grew by more than total generation.

```js
// A Missing Value Stops the Chart Instead of Being Read as Zero (the Paired Countries Have None)
const known = (v, what) => {
  if (v === null || v === undefined || Number.isNaN(v)) throw new Error(`Missing ${what}`);
  return v;
};

const describe = (d) => {
  const at = (year) => countryYear.find((r) => r.iso3 === d.iso3 && r.year === year);
  const start = at(2000);
  const end = at(2024);
  const base = known(start.generation_twh, `${d.country} generation in 2000`);
  return {
    country: d.country,
    group: groupOf(d),
    demandGrowth: d.demand_growth_pct,
    generationGrowth: 100 * (known(end.generation_twh, `${d.country} generation in 2024`) / base - 1),
    mix: mixSources.map((s) => ({...s, share: d3.sum(s.columns, (c) => known(d[`${c}_share_pct_2000`], `${d.country} ${c} share in 2000`))})),
    changes: changeKinds.map((k) => {
      const twh = known(end[k.column], `${d.country} ${k.column} in 2024`) - known(start[k.column], `${d.country} ${k.column} in 2000`);
      return {...k, twh, pct: (100 * twh) / base};
    })
  };
};
```
