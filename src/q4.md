# Q4: What Drove the Largest Changes in the Share of Electricity Generation from Clean Sources, and How the Mix Evolved, 2000–2024

**Question:** In the countries with the largest increases and decreases in clean share, how much did wind, solar, hydro, nuclear, bioenergy, and other renewables each contribute, and how did each country's mix of clean sources change from year to year?

This page looks at **clean sources of electricity generation**, not overall energy use. Clean means renewables plus nuclear, as a percentage of a country's domestic electricity generation. Fuels burned for transport, heating, and industry are not included.

We explore the question with three plots:

1. **[Clean Source Contributions in the Largest Increases](#clean-source-contributions-in-the-largest-increases)** is a diverging stacked horizontal bar chart for the countries whose clean share rose the most.
2. **[Clean Source Contributions in the Largest Decreases](#clean-source-contributions-in-the-largest-decreases)** is the same chart for the countries whose clean share fell the most.
3. **[Clean Source Mix Over Time](#clean-source-mix-over-time)** is an animated vertical stacked bar chart of the clean source mix of selected countries, year by year.

The three plots answer the same question in different ways. They differ in what they make easy to read.

| | Largest Increases | Largest Decreases | Clean Source Mix Over Time |
|---|---|---|---|
| **Shows** | How much each clean source added to, or took away from, the clean share or output of the countries that gained the most | The same breakdown for the countries whose clean share fell the most | The clean source mix of each selected country in every year from 2000 to 2024, as stacked bars |
| **Strengths** | Each source's contribution is visible as a segment, and a source that declined extends left of zero instead of being hidden. The black diamond gives the net change without subtracting by eye. | The same diverging layout lets the losses be compared with the gains on the increases chart, and shows which sources fell and which partly offset the decline. | The stack height is the clean share directly, countries sit side by side, and the path between 2000 and 2024 is visible, including when each source grew. |
| **Weaknesses** | It compares only the two endpoints, so the timing of the change is hidden. Segments in the middle of a stack have no common baseline, so they are harder to compare than bar lengths. | Same as the increases chart. It also covers only the largest decreases, so countries with small falls are not shown. | Only one year is visible at a time, so changes must be followed through the animation or the slider. Segments in the middle of a stack are harder to compare than bar lengths. |
| **Best For** | Seeing which sources drove a large rise in clean share | Seeing which sources drove a large fall in clean share | Understanding how and when a country's clean source mix evolved |

Reading them together gives the fullest picture: use the first two plots to see which sources drove the biggest gains and losses between 2000 and 2024, and the third to see how each country's mix changed along the way.

All three plots have a **Full Screen** button in their toolbar. Full screen enlarges the plot, and its controls stay available there. The Countries sliders in the three plots are linked: moving one moves the others to the same value, so you only set it once.

```js
// Draw One Diverging Stacked Bar Chart into a Panel (Positive Segments Stack Right of Zero, Negative Left)
function drawBreakdown(rows, {panel, state, isShare, direction}) {
  const column = (s) => (isShare ? s.share : s.twh);
  const unit = isShare ? "pp" : "TWh";

  const dims = {
    width: 800,
    rowHeight: 30,
    marginTop: 80,
    marginRight: 30,
    marginBottom: 55,
    marginLeft: 120
  };

  const innerHeight = rows.length * dims.rowHeight;
  const totalWidth = dims.marginLeft + dims.width + dims.marginRight;
  const totalHeight = innerHeight + dims.marginTop + dims.marginBottom;

  const svg = d3.create("svg")
    .attr("width", totalWidth)
    .attr("height", totalHeight)
    .attr("viewBox", [0, 0, totalWidth, totalHeight])
    .attr("style", "max-width: 100%; height: auto; font: 11px sans-serif;");

  svg.append("text")
    .attr("x", totalWidth / 2)
    .attr("y", 28)
    .attr("text-anchor", "middle")
    .attr("font-size", 20)
    .attr("font-weight", 700)
    .text(`${isShare ? "Share" : "Output"} Changes in Clean Generation by Source, ${direction}, 2000–2024`);

  // Stack Each Country's Source Changes (Diverging Offset Keeps Negatives Left of Zero)
  const stacked = d3.stack()
    .keys(sources.map(column))
    .offset(d3.stackOffsetDiverging)(rows);

  const x = d3.scaleLinear()
    .domain([d3.min(stacked, (s) => d3.min(s, (r) => r[0])), d3.max(stacked, (s) => d3.max(s, (r) => r[1]))])
    .nice()
    .range([0, dims.width]);

  const y = d3.scaleBand()
    .domain(rows.map((d) => d.country))
    .range([0, innerHeight])
    .padding(0.2);

  // Net Change per Country: the Sum of its Source Changes in the Selected Measure
  const netChange = (d) => d3.sum(sources, (s) => d[column(s)]);

  const g = svg.append("g")
    .attr("transform", `translate(${dims.marginLeft}, ${dims.marginTop})`);

  // Vertical Gridlines
  g.append("g")
    .selectAll("line")
    .data(x.ticks(8))
    .join("line")
    .attr("x1", (d) => x(d))
    .attr("x2", (d) => x(d))
    .attr("y1", 0)
    .attr("y2", innerHeight)
    .attr("stroke", "currentColor")
    .attr("stroke-opacity", 0.1);

  // One Group per Source, One Segment per Country
  g.append("g")
    .selectAll("g")
    .data(stacked)
    .join("g")
    .attr("fill", (s, i) => sources[i].color)
    .attr("class", "highlightable")
    .attr("data-source", (s, i) => sources[i].name)
    .selectAll("rect")
    .data((s, i) => s.map((r) => ({segment: r, source: sources[i]})))
    .join("rect")
    .attr("x", (d) => x(Math.min(d.segment[0], d.segment[1])))
    .attr("y", (d) => y(d.segment.data.country))
    .attr("width", (d) => Math.abs(x(d.segment[1]) - x(d.segment[0])))
    .attr("height", y.bandwidth())
    .attr("stroke", "#ffffff")
    .attr("stroke-width", 0.75)
    .append("title")
    .text((d) => `${d.segment.data.country}\n${d.source.name}: ${signed(d.segment.data[column(d.source)])} ${unit}\nNet Change: ${signed(netChange(d.segment.data))} ${unit}`);

  // Zero Baseline
  g.append("line")
    .attr("x1", x(0))
    .attr("x2", x(0))
    .attr("y1", 0)
    .attr("y2", innerHeight)
    .attr("stroke", "currentColor");

  // Net Change Markers (Diamond at the Net Position, Value Shown on Hover)
  const netRows = g.append("g")
    .selectAll("g")
    .data(rows)
    .join("g")
    .attr("transform", (d) => `translate(0, ${y(d.country) + y.bandwidth() / 2})`);

  netRows.append("path")
    .attr("transform", (d) => `translate(${x(netChange(d))}, 0)`)
    .attr("d", netDiamond)
    .attr("fill", "currentColor")
    .attr("stroke", "#ffffff")
    .attr("stroke-width", 1.5)
    .append("title")
    .text((d) => `${d.country}\nNet Change: ${signed(netChange(d))} ${unit}`);

  // Country Labels
  g.append("g")
    .selectAll("text")
    .data(rows)
    .join("text")
    .attr("x", -8)
    .attr("y", (d) => y(d.country) + y.bandwidth() / 2)
    .attr("dy", "0.35em")
    .attr("text-anchor", "end")
    .text((d) => d.country);

  // X Axis
  g.append("g")
    .attr("transform", `translate(0, ${innerHeight})`)
    .call(d3.axisBottom(x).ticks(8))
    .call((a) => a.select(".domain").remove());

  g.append("text")
    .attr("x", dims.width / 2)
    .attr("y", innerHeight + 42)
    .attr("text-anchor", "middle")
    .text(isShare ? "Change in Share of Total Electricity Generation (Percentage Points)" : "Change in Electricity Generation (TWh)");

  // Legend Across the Top (Hover to Highlight a Source, Click or Press Enter to Pin it)
  const legend = svg.append("g")
    .attr("transform", `translate(${dims.marginLeft}, 48)`);

  // Dim Every Source Except the Hovered One (or the Pinned One when Nothing is Hovered)
  function highlight(hovered) {
    const active = hovered ?? state.pinned;
    g.selectAll("g.highlightable").classed("is-dimmed", function () {
      return active != null && this.dataset.source !== active;
    });
    legend.selectAll("g.legend-item")
      .classed("is-dimmed", function () { return active != null && this.dataset.source !== active; })
      .classed("is-pinned", function () { return this.dataset.source === state.pinned; })
      .attr("aria-pressed", function () { return String(this.dataset.source === state.pinned); });
  }

  sources.forEach((s, i) => {
    const item = legend.append("g")
      .attr("class", "legend-item")
      .attr("data-source", s.name)
      .attr("transform", `translate(${i * 120}, 0)`)
      .attr("tabindex", 0)
      .attr("role", "button")
      .attr("aria-label", `Highlight ${s.name}`)
      .on("mouseenter focus", () => highlight(s.name))
      .on("mouseleave blur", () => highlight(null))
      .on("click", () => {
        state.pinned = state.pinned === s.name ? null : s.name;
        highlight(s.name);
      })
      .on("keydown", (event) => {
        if (event.key === "Enter" || event.key === " ") {
          event.preventDefault();
          state.pinned = state.pinned === s.name ? null : s.name;
          highlight(s.name);
        }
      });
    item.append("rect").attr("class", "legend-hit").attr("x", -4).attr("y", -4).attr("width", 112).attr("height", 20).attr("rx", 4);
    item.append("rect").attr("width", 12).attr("height", 12).attr("fill", s.color);
    item.append("text").attr("x", 18).attr("y", 10).text(s.name);
  });

  // Net Change Legend Entry (Not Interactive; the Diamonds Stay Visible While a Source is Highlighted)
  const netLegend = legend.append("g").attr("transform", `translate(${sources.length * 120}, 0)`);
  netLegend.append("path").attr("transform", "translate(6, 6)").attr("d", netDiamond).attr("fill", "currentColor");
  netLegend.append("text").attr("x", 18).attr("y", 10).text("Net Change");

  // Restore a Pinned Highlight after a Redraw
  highlight(null);

  panel.setChart(svg.node());
}
```

## Clean Source Contributions in the Largest Increases

Each bar splits one country's change in clean generation into the sources that made it up, using the countries with the largest increases in clean share. We chose stacked bars because the question is about parts of a total: the stack shows how much each source added or took away. The stack is diverging so that a source that declined, such as nuclear in some countries, extends left of zero instead of being hidden. A black diamond marks each country's net change, which is the positive side minus the negative side, so it does not have to be subtracted by eye. Each source keeps one color across the whole page, and the bioenergy color is chosen to be distinct from hydro.

Use the slider to change how many countries are shown, and switch the measure between the change in **share** (percentage points) and the change in **output** (TWh). Hover a segment for a tooltip with the country's name, the source's change, and the country's net change, in the unit currently selected (percentage points or TWh). Hover the black diamond for a tooltip with the country's name and net change. Hover a legend item to dim the other sources and highlight that source in every row, and click it (or press Enter) to keep the highlight; click it again to clear.

## Clean Source Mix Over Time

The two charts above compare 2000 with 2024. This chart fills in the years between by showing the clean source mix of each selected country, one year at a time. Each bar is a country, stacked by source as a percentage of that country's total electricity generation, so the height of a bar is its clean share and the empty space above it is everything that is not clean. We chose vertical stacked bars because the stack height shows the total clean share directly, countries sit side by side, and time is carried by the animation instead of an axis. The vertical scale is fixed at 0–100%, so a bar can only grow or shrink for a real change. Only one year is visible at a time, so use the line chart in Q3 to see a country's whole path at once.

Press **Play** to step through the years from 2000 to 2024, and **Pause** to stop. Drag the **Year** slider to jump to a year, which also pauses the animation. Tick the checkboxes to choose which countries are drawn; the chart starts with the three largest increases and the three largest decreases. **Largest Increases** and **Largest Decreases** select the top countries in one click, and the **Countries per Preset** slider sets how many; moving it updates the selection while a preset is active. **Clear** empties the selection. Hover a segment for a tooltip with the country's name, the year, and that source's share of generation and TWh (a country with no data for the year shows "No data"), and hover a legend item to dim the other sources, or click it (or press Enter) to keep the highlight.
