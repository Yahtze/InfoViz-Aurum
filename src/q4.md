# Q4: What Drove the Largest Gains in the Share of Electricity Generation from Clean Sources, 2000–2024

**Question:** In the countries with the largest increases in clean share, how much did wind, solar, hydro, nuclear, bioenergy, and other renewables each contribute?

This page looks at **clean sources of electricity generation**, not overall energy use. Clean means renewables plus nuclear, as a percentage of a country's domestic electricity generation. Fuels burned for transport, heating, and industry are not included.

We explore the question with one plot:

1. **[Clean Source Contributions](#clean-source-contributions)** is a diverging stacked horizontal bar chart.

The plot has a **Full Screen** button in its toolbar. Full screen enlarges the plot, and its controls stay available there.

## Clean Source Contributions

Each bar splits one country's change in clean generation into the sources that made it up, using the countries with the largest increases in clean share. We chose stacked bars because the question is about parts of a total: the stack shows how much each source added or took away. The stack is diverging so that a source that declined, such as nuclear in some countries, extends left of zero instead of being hidden. Each source keeps one color across the whole page.

Use the slider to change how many countries are shown, and switch the measure between the change in **share** (percentage points) and the change in **output** (TWh). Hover a segment for its exact value.

```js
// Load the Comparison Table (One Row per Compared Country)
const comparison = await FileAttachment("data/comparison_2000_2024.csv").csv({typed: true});
```

```js
// Create the Controls for the Number of Countries and the Measure Shown
const countInput = Inputs.range([3, 20], {label: "Countries", step: 1, value: 10});
panel.addControl(countInput);

const measureInput = Inputs.radio(["Share (Percentage Points)", "Output (TWh)"], {label: "Measure", value: "Share (Percentage Points)"});
```

```js
// Pick the Countries with the Largest Clean-Share Gains (Ties Broken by Country Name)
const gainers = comparison
  .filter((d) => d.d_clean_share_pp > 0)
  .sort((a, b) => d3.descending(a.d_clean_share_pp, b.d_clean_share_pp) || d3.ascending(a.country, b.country))
  .slice(0, count);

// Clean Sources in Stack Order, with Column Names for Each Measure
const sources = [
  {name: "Wind", color: "#4878a8", share: "d_wind_share_pp", twh: "d_wind_twh"},
  {name: "Solar", color: "#e5ac28", share: "d_solar_share_pp", twh: "d_solar_twh"},
  {name: "Hydro", color: "#3fa7a3", share: "d_hydro_share_pp", twh: "d_hydro_twh"},
  {name: "Nuclear", color: "#8e6bbb", share: "d_nuclear_share_pp", twh: "d_nuclear_twh"},
  {name: "Bioenergy", color: "#5a9a74", share: "d_bioenergy_share_pp", twh: "d_bioenergy_twh"},
  {name: "Other Renewables", color: "#b0894f", share: "d_other_renewables_excluding_bioenergy_share_pp", twh: "d_other_renewables_excluding_bioenergy_twh"}
];
```

```js
// Draw the Diverging Stacked Bars (Positive Segments Stack Right of Zero, Negative Left)
const isShare = measure === "Share (Percentage Points)";
const column = (s) => (isShare ? s.share : s.twh);
const unit = isShare ? "pp" : "TWh";

const dims = {
  width: 800,
  rowHeight: 30,
  marginTop: 80,
  marginRight: 30,
  marginBottom: 55,
  marginLeft: 120
};

const innerHeight = gainers.length * dims.rowHeight;
const totalWidth = dims.marginLeft + dims.width + dims.marginRight;
const totalHeight = innerHeight + dims.marginTop + dims.marginBottom;

const svg = d3.create("svg")
  .attr("width", totalWidth)
  .attr("height", totalHeight)
  .attr("viewBox", [0, 0, totalWidth, totalHeight])
  .attr("style", "max-width: 100%; height: auto; font: 11px sans-serif;");

svg.append("text")
  .attr("x", totalWidth / 2)
  .attr("y", 28)
  .attr("text-anchor", "middle")
  .attr("font-size", 20)
  .attr("font-weight", 700)
  .text(`Clean Electricity Generation by Source: ${isShare ? "Share" : "Output"} Changes, 2000–2024`);

// Stack Each Country's Source Changes (Diverging Offset Keeps Negatives Left of Zero)
const stacked = d3.stack()
  .keys(sources.map(column))
  .offset(d3.stackOffsetDiverging)(gainers);

const x = d3.scaleLinear()
  .domain([d3.min(stacked, (s) => d3.min(s, (r) => r[0])), d3.max(stacked, (s) => d3.max(s, (r) => r[1]))])
  .nice()
  .range([0, dims.width]);

const y = d3.scaleBand()
  .domain(gainers.map((d) => d.country))
  .range([0, innerHeight])
  .padding(0.2);

const signed = d3.format("+.1f");

const g = svg.append("g")
  .attr("transform", `translate(${dims.marginLeft}, ${dims.marginTop})`);

// Vertical Gridlines
g.append("g")
  .selectAll("line")
  .data(x.ticks(8))
  .join("line")
  .attr("x1", (d) => x(d))
  .attr("x2", (d) => x(d))
  .attr("y1", 0)
  .attr("y2", innerHeight)
  .attr("stroke", "currentColor")
  .attr("stroke-opacity", 0.1);

// One Group per Source, One Segment per Country
g.append("g")
  .selectAll("g")
  .data(stacked)
  .join("g")
  .attr("fill", (s, i) => sources[i].color)
  .selectAll("rect")
  .data((s, i) => s.map((r) => ({segment: r, source: sources[i]})))
  .join("rect")
  .attr("x", (d) => x(Math.min(d.segment[0], d.segment[1])))
  .attr("y", (d) => y(d.segment.data.country))
  .attr("width", (d) => Math.abs(x(d.segment[1]) - x(d.segment[0])))
  .attr("height", y.bandwidth())
  .append("title")
  .text((d) => `${d.segment.data.country}\n${d.source.name}: ${signed(d.segment.data[column(d.source)])} ${unit}\nTotal Clean-Share Change: ${signed(d.segment.data.d_clean_share_pp)} pp`);

// Zero Baseline
g.append("line")
  .attr("x1", x(0))
  .attr("x2", x(0))
  .attr("y1", 0)
  .attr("y2", innerHeight)
  .attr("stroke", "currentColor");

// Country Labels
g.append("g")
  .selectAll("text")
  .data(gainers)
  .join("text")
  .attr("x", -8)
  .attr("y", (d) => y(d.country) + y.bandwidth() / 2)
  .attr("dy", "0.35em")
  .attr("text-anchor", "end")
  .text((d) => d.country);

// X Axis
g.append("g")
  .attr("transform", `translate(0, ${innerHeight})`)
  .call(d3.axisBottom(x).ticks(8))
  .call((a) => a.select(".domain").remove());

g.append("text")
  .attr("x", dims.width / 2)
  .attr("y", innerHeight + 42)
  .attr("text-anchor", "middle")
  .text(isShare ? "Change in Share of Total Electricity Generation (Percentage Points)" : "Change in Electricity Generation (TWh)");

// Legend Across the Top
const legend = svg.append("g")
  .attr("transform", `translate(${dims.marginLeft}, 48)`);

sources.forEach((s, i) => {
  const item = legend.append("g").attr("transform", `translate(${i * 120}, 0)`);
  item.append("rect").attr("width", 12).attr("height", 12).attr("fill", s.color);
  item.append("text").attr("x", 18).attr("y", 10).text(s.name);
});

panel.setChart(svg.node());
```

<p style="font-size: 12px; opacity: 0.7;">
Source: OWID. Clean = renewables + nuclear, measured on electricity generation rather than total energy use. Ranked by percentage-point gain in clean share, up to ${count} countries; ties are broken by country name.
Other Renewables is OWID's "other renewables excluding bioenergy", mainly geothermal, tidal, and wave; OWID does not report these separately.
Segments are an accounting breakdown, not proof of cause.
TWh changes need not follow share changes: growing demand can raise output even as a share falls.
</p>
