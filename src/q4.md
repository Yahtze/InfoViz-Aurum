# Q4: What Drove the Largest Changes in the Share of Electricity Generation from Clean Sources, and How the Mix Evolved, 2000–2024

<div class="question">
<span class="question-label">Guiding Question</span>

In the countries with the largest increases and decreases in clean share, how much did wind, solar, hydro, nuclear, bioenergy, and other renewables each contribute, and how did each country's mix of clean sources change from year to year?

</div>

## The Short Answer

Among the ten countries with the largest gains in clean share, ${q4Facts.upLeader.name} is the largest contributor in ${q4Facts.upLeader.count} of them, and ${q4Facts.upTotals[0].name.toLowerCase()} alone added a combined ${q4Facts.upTotals[0].pp} points across the ten. Among the ten largest losses, ${q4Facts.downLeader.name} is the largest contributor in ${q4Facts.downLeader.count}, and ${q4Facts.downTotals[0].name.toLowerCase()} changed by a combined ${q4Facts.downTotals[0].pp} points.

## How to Read This Page

The three plots follow the question from the gains, to the losses, to the years in between.

1. **[What Drove the Gains?](#clean-source-contributions-in-the-largest-increases)** Stacked bars split each country's gain into the sources behind it.
2. **[What Drove the Losses?](#clean-source-contributions-in-the-largest-decreases)** The same chart for the countries whose clean share fell, so the two can be compared directly.
3. **[How Did the Mix Evolve?](#clean-source-mix-over-time)** The animation fills in the years between 2000 and 2024. Start with the default selection, then pick countries from the first two charts and press Play.

Each plot has a collapsible **Specific Interactions** note just above it; open it for how to use that plot's controls.

```js
// Facts Quoted in the Page Text, Computed from the Data so the Numbers Cannot Drift from the Charts
const q4Facts = (() => {
  const summarize = (rows) => {
    const totals = sources
      .map((s) => ({name: s.name, sum: d3.sum(rows, (d) => d[s.share])}))
      .sort((a, b) => d3.descending(Math.abs(a.sum), Math.abs(b.sum)))
      .map((t) => ({name: t.name, pp: Math.abs(t.sum).toFixed(0)}));
    const leaders = d3.rollups(rows, (v) => v.length, (d) => d3.greatest(sources, (s) => Math.abs(d[s.share])).name)
      .sort((a, b) => d3.descending(a[1], b[1]));
    return {totals, leader: {name: leaders[0][0], count: leaders[0][1]}};
  };
  const up = summarize(pickCountries("up", 10));
  const down = summarize(pickCountries("down", 10));
  return {upTotals: up.totals, upLeader: up.leader, downTotals: down.totals, downLeader: down.leader};
})();
```

```js
// Draw One Diverging Stacked Bar Chart into a Panel (Positive Segments Stack Right of Zero, Negative Left)
function drawBreakdown(rows, {panel, state, isShare, direction}) {
  const column = (s) => (isShare ? s.share : s.twh);
  const unit = isShare ? "pp" : "TWh";

  const dims = {
    width: 800,
    rowHeight: 30,
    marginTop: 80,
    marginRight: 30,
    marginBottom: 55,
    marginLeft: 120
  };

  const innerHeight = rows.length * dims.rowHeight;
  const totalWidth = dims.marginLeft + dims.width + dims.marginRight;
  const totalHeight = innerHeight + dims.marginTop + dims.marginBottom;

  const svg = d3.create("svg")
    .attr("width", totalWidth)
    .attr("height", totalHeight)
    .attr("viewBox", [0, 0, totalWidth, totalHeight])
    .attr("style", "max-width: 100%; height: auto; font: 11px sans-serif;");

  svg.append("text")
    .attr("x", totalWidth / 2)
    .attr("y", 28)
    .attr("text-anchor", "middle")
    .attr("font-size", 20)
    .attr("font-weight", 700)
    .text(`${isShare ? "Share" : "Output"} Changes in Clean Generation by Source, ${direction}, 2000–2024`);

  // Stack Each Country's Source Changes (Diverging Offset Keeps Negatives Left of Zero)
  const stacked = d3.stack()
    .keys(sources.map(column))
    .offset(d3.stackOffsetDiverging)(rows);

  const x = d3.scaleLinear()
    .domain([d3.min(stacked, (s) => d3.min(s, (r) => r[0])), d3.max(stacked, (s) => d3.max(s, (r) => r[1]))])
    .nice()
    .range([0, dims.width]);

  const y = d3.scaleBand()
    .domain(rows.map((d) => d.country))
    .range([0, innerHeight])
    .padding(0.2);

  // Net Change per Country: the Sum of its Source Changes in the Selected Measure
  const netChange = (d) => d3.sum(sources, (s) => d[column(s)]);

  const g = svg.append("g")
    .attr("transform", `translate(${dims.marginLeft}, ${dims.marginTop})`);

  // Vertical Gridlines
  g.append("g")
    .selectAll("line")
    .data(x.ticks(8))
    .join("line")
    .attr("x1", (d) => x(d))
    .attr("x2", (d) => x(d))
    .attr("y1", 0)
    .attr("y2", innerHeight)
    .attr("stroke", "currentColor")
    .attr("stroke-opacity", 0.1);

  // One Group per Source, One Segment per Country
  g.append("g")
    .selectAll("g")
    .data(stacked)
    .join("g")
    .attr("fill", (s, i) => sources[i].color)
    .attr("class", "highlightable")
    .attr("data-source", (s, i) => sources[i].name)
    .selectAll("rect")
    .data((s, i) => s.map((r) => ({segment: r, source: sources[i]})))
    .join("rect")
    .attr("x", (d) => x(Math.min(d.segment[0], d.segment[1])))
    .attr("y", (d) => y(d.segment.data.country))
    .attr("width", (d) => Math.abs(x(d.segment[1]) - x(d.segment[0])))
    .attr("height", y.bandwidth())
    .attr("stroke", "#ffffff")
    .attr("stroke-width", 0.75)
    .append("title")
    .text((d) => `${d.segment.data.country}\n${d.source.name}: ${signed(d.segment.data[column(d.source)])} ${unit}\nNet Change: ${signed(netChange(d.segment.data))} ${unit}`);

  // Zero Baseline
  g.append("line")
    .attr("x1", x(0))
    .attr("x2", x(0))
    .attr("y1", 0)
    .attr("y2", innerHeight)
    .attr("stroke", "currentColor");

  // Net Change Markers (Diamond at the Net Position, Value Shown on Hover)
  const netRows = g.append("g")
    .selectAll("g")
    .data(rows)
    .join("g")
    .attr("transform", (d) => `translate(0, ${y(d.country) + y.bandwidth() / 2})`);

  netRows.append("path")
    .attr("transform", (d) => `translate(${x(netChange(d))}, 0)`)
    .attr("d", netDiamond)
    .attr("fill", "currentColor")
    .attr("stroke", "#ffffff")
    .attr("stroke-width", 1.5)
    .append("title")
    .text((d) => `${d.country}\nNet Change: ${signed(netChange(d))} ${unit}`);

  // Country Labels
  g.append("g")
    .selectAll("text")
    .data(rows)
    .join("text")
    .attr("x", -8)
    .attr("y", (d) => y(d.country) + y.bandwidth() / 2)
    .attr("dy", "0.35em")
    .attr("text-anchor", "end")
    .text((d) => d.country);

  // X Axis
  g.append("g")
    .attr("transform", `translate(0, ${innerHeight})`)
    .call(d3.axisBottom(x).ticks(8))
    .call((a) => a.select(".domain").remove());

  g.append("text")
    .attr("x", dims.width / 2)
    .attr("y", innerHeight + 42)
    .attr("text-anchor", "middle")
    .text(isShare ? "Change in Share of Total Electricity Generation (Percentage Points)" : "Change in Electricity Generation (TWh)");

  // Legend Across the Top (Hover to Highlight a Source, Click or Press Enter to Pin it)
  const legend = svg.append("g")
    .attr("transform", `translate(${dims.marginLeft}, 48)`);

  // Dim Every Source Except the Hovered One (or the Pinned One when Nothing is Hovered)
  function highlight(hovered) {
    const active = hovered ?? state.pinned;
    g.selectAll("g.highlightable").classed("is-dimmed", function () {
      return active != null && this.dataset.source !== active;
    });
    legend.selectAll("g.legend-item")
      .classed("is-dimmed", function () { return active != null && this.dataset.source !== active; })
      .classed("is-pinned", function () { return this.dataset.source === state.pinned; })
      .attr("aria-pressed", function () { return String(this.dataset.source === state.pinned); });
  }

  sources.forEach((s, i) => {
    const item = legend.append("g")
      .attr("class", "legend-item")
      .attr("data-source", s.name)
      .attr("transform", `translate(${i * 120}, 0)`)
      .attr("tabindex", 0)
      .attr("role", "button")
      .attr("aria-label", `Highlight ${s.name}`)
      .on("mouseenter focus", () => highlight(s.name))
      .on("mouseleave blur", () => highlight(null))
      .on("click", () => {
        state.pinned = state.pinned === s.name ? null : s.name;
        highlight(s.name);
      })
      .on("keydown", (event) => {
        if (event.key === "Enter" || event.key === " ") {
          event.preventDefault();
          state.pinned = state.pinned === s.name ? null : s.name;
          highlight(s.name);
        }
      });
    item.append("rect").attr("class", "legend-hit").attr("x", -4).attr("y", -4).attr("width", 112).attr("height", 20).attr("rx", 4);
    item.append("rect").attr("width", 12).attr("height", 12).attr("fill", s.color);
    item.append("text").attr("x", 18).attr("y", 10).text(s.name);
  });

  // Net Change Legend Entry (Not Interactive; the Diamonds Stay Visible While a Source is Highlighted)
  const netLegend = legend.append("g").attr("transform", `translate(${sources.length * 120}, 0)`);
  netLegend.append("path").attr("transform", "translate(6, 6)").attr("d", netDiamond).attr("fill", "currentColor");
  netLegend.append("text").attr("x", 18).attr("y", 10).text("Net Change");

  // Restore a Pinned Highlight after a Redraw
  highlight(null);

  panel.setChart(svg.node());
}
```

## Clean Source Mix Over Time

<p class="bridge">The two endpoint charts hide the timing, so this animation shows how each country's mix changed year by year.</p>

This animation shows the clean source mix of each selected country one year at a time from 2000 to 2024, and a Year Range view compares any two years side by side. It answers the last part of the guiding question, how each country's mix changed from year to year, which the two charts above cannot show because they compare only 2000 and 2024.

```js
  const range = timeView.mode === "range";
  const yearOf = {a: range ? timeView.from : +yearInput.value, b: timeView.to};
  yearLabel.text(range ? `${timeView.from} → ${timeView.to}` : yearInput.value);
  rangeKey.text(`Left Bar: ${timeView.from} · Right Bar: ${timeView.to}`).attr("opacity", range ? 0.7 : 0);

  const t = timeSvg.transition().duration(duration).ease(d3.easeLinear);
  const gap = 4;
  const half = (timeX.bandwidth() - gap) / 2;
  const geometry = {
    a: range ? {x: 0, width: half} : {x: 0, width: timeX.bandwidth()},
    b: range ? {x: half + gap, width: half} : {x: 0, width: timeX.bandwidth()}
  };

  bars.each(function ({name, slot}) {
    const year = yearOf[slot];
    const row = timeRows.get(name).get(year);
    const known = row && row.clean_share_pct !== "";
    const {x, width} = geometry[slot];
    const visible = slot === "a" || range;
    let base = 0;

    d3.select(this).attr("pointer-events", visible ? null : "none")
      .transition(t).attr("opacity", visible ? 1 : 0);

    d3.select(this).selectAll("rect").each(function (d) {
      const value = known ? +row[levelColumn(d.source)] || 0 : 0;
      const top = timeY(base + value);
      const bottom = timeY(base);
      d3.select(this)
        .transition(t)
        .attr("x", x)
        .attr("width", width)
        .attr("y", top)
        .attr("height", bottom - top);
      d3.select(this).select("title").text(known
        ? `${name}, ${year}\n${d.source.name}: ${timePct(value)}% of generation (${d3.format(",.1f")(+row[d.source.twh.replace(/^d_/, "")] || 0)} TWh)`
        : `${name}, ${year}\nNo data`);
      base += value;
    });

    d3.select(this).select("text.bar-total")
      .attr("font-size", range ? 10 : 11)
      .text(known ? `${timePct(+row.clean_share_pct)}%` : "No Data")
      .transition(t)
      .attr("x", x + width / 2)
      .attr("y", known ? timeY(base) - 6 : timeDims.height - 6);
  });

  // Change in Clean Share across the Range (Teal for a Rise, Rust for a Fall; Blank if either Year is Unknown)
  changeLabels.each(function (name) {
    const from = timeRows.get(name).get(timeView.from);
    const to = timeRows.get(name).get(timeView.to);
    const change = from?.clean_share_pct && to?.clean_share_pct ? +to.clean_share_pct - +from.clean_share_pct : null;
    d3.select(this)
      .text(change == null ? "n/a" : `${signed(change)} pp`)
      .attr("fill", change == null ? "currentColor" : change >= 0 ? "#24857a" : "#b5614a")
      .transition(t)
      .attr("opacity", range ? 1 : 0);
  });
};

timeChart.update(0);
timeHighlight(null);

timePanel.setChart(timeSvg.node());
```

## Comparison of the Visualizations

| | Largest Increases | Largest Decreases | Clean Source Mix Over Time |
|---|---|---|---|
| **Shows** | How much each clean source added to, or took away from, the clean share or output of the countries that gained the most | The same breakdown for the countries whose clean share fell the most | The clean source mix of each selected country in every year from 2000 to 2024, as stacked bars |
| **Strengths** | Each source's contribution is visible as a segment, and a source that declined extends left of zero instead of being hidden. The black diamond gives the net change without subtracting by eye. | The same diverging layout lets the losses be compared with the gains on the increases chart, and shows which sources fell and which partly offset the decline. | The stack height is the clean share directly, countries sit side by side, and the path between 2000 and 2024 is visible, including when each source grew. |
| **Weaknesses** | It compares only the two endpoints, so the timing of the change is hidden. Segments in the middle of a stack have no common baseline, so they are harder to compare than bar lengths. | Same as the increases chart. It also covers only the largest decreases, so countries with small falls are not shown. | In the single year view only one year is visible at a time, so changes must be followed through the animation or slider; the year range view compares just two years, so the years between them are not shown. Segments in the middle of a stack are harder to compare than bar lengths. |
| **Best For** | Seeing which sources drove a large rise in clean share | Seeing which sources drove a large fall in clean share | Understanding how and when a country's clean source mix evolved |
