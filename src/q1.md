# Q1: The Global Electricity Mix, 2000–2024

How has the global electricity mix changed from 2000 to 2024, in both percentage shares and absolute generation (TWh)?
Both charts stack the same eight sources: fossil sources in grays at the bottom, clean sources in color above them.
The left chart shows each source's **share** of generation; the right chart shows its **output** in TWh, so the top of the stack is total generation.
Move the mouse across either chart to see every source for that year.

```js
// Load the Country-by-Year Table and Keep the World Rows
const countryYear = await FileAttachment("data/country_year.csv").csv({typed: true});

const world = countryYear
  .filter((d) => d.country === "World" && d.year >= 2000 && d.year <= 2024)
  .sort((a, b) => d3.ascending(a.year, b.year));
```

```js
// Sources in Stack Order (Bottom to Top): Fossil Grays, then the Q4 Clean Colors
// Other Clean Combines Bioenergy with Other Renewables Excluding Bioenergy
const sources = [
  {name: "Coal", group: "Fossil", color: "#77716b", columns: ["coal"]},
  {name: "Gas", group: "Fossil", color: "#a29c96", columns: ["gas"]},
  {name: "Oil", group: "Fossil", color: "#cbc5bf", columns: ["oil"]},
  {name: "Wind", group: "Clean", color: "#4878a8", columns: ["wind"]},
  {name: "Solar", group: "Clean", color: "#e5ac28", columns: ["solar"]},
  {name: "Hydro", group: "Clean", color: "#3fa7a3", columns: ["hydro"]},
  {name: "Nuclear", group: "Clean", color: "#8e6bbb", columns: ["nuclear"]},
  {name: "Other Clean", group: "Clean", color: "#5a9a74", columns: ["bioenergy", "other_renewables_excluding_bioenergy"]}
];

// One Row per Year with Each Source's Share (%) and Output (TWh)
// A Missing Value Stops the Page Instead of Being Read as Zero (the World Rows Have None)
const sumKnown = (d, columns) => {
  if (columns.some((c) => d[c] === null || d[c] === undefined || Number.isNaN(d[c]))) {
    throw new Error(`Missing ${columns.join(" + ")} for World in ${d.year}`);
  }
  return d3.sum(columns, (c) => d[c]);
};

const mix = world.map((d) => {
  const row = {year: d.year, total: d.generation_twh, fossilShare: d.fossil_share_pct, fossilTwh: d.fossil_twh, cleanShare: d.clean_share_pct, cleanTwh: d.clean_twh};
  for (const s of sources) {
    row[`${s.name} share`] = sumKnown(d, s.columns.map((c) => `${c}_share_pct`));
    row[`${s.name} twh`] = sumKnown(d, s.columns.map((c) => `${c}_twh`));
  }
  return row;
});

const first = mix[0];
const last = mix[mix.length - 1];
```

```js
// Draw the Two Stacked Area Charts Side by Side, with a Shared Year Cursor
const dims = {
  chartWidth: 380,
  chartHeight: 300,
  gap: 90,
  marginTop: 110,
  marginRight: 30,
  marginBottom: 50,
  marginLeft: 70
};

const totalWidth = dims.marginLeft + 2 * dims.chartWidth + dims.gap + dims.marginRight;
const totalHeight = dims.marginTop + dims.chartHeight + dims.marginBottom;

const svg = d3.create("svg")
  .attr("width", totalWidth)
  .attr("height", totalHeight)
  .attr("viewBox", [0, 0, totalWidth, totalHeight])
  .attr("style", "max-width: 100%; height: auto; font: 11px sans-serif;");

svg.append("text")
  .attr("x", totalWidth / 2)
  .attr("y", 22)
  .attr("text-anchor", "middle")
  .attr("font-size", 14)
  .attr("font-weight", 500)
  .text("World Electricity Generation by Source, 2000–2024");

// Legend Across the Top, Grouped into Fossil and Clean so the Split Does not Rely on Color Alone
const legend = svg.append("g").attr("transform", `translate(${dims.marginLeft}, 44)`);
let legendX = 0;
for (const group of ["Fossil", "Clean"]) {
  legend.append("text")
    .attr("x", legendX)
    .attr("y", 10)
    .attr("font-weight", 600)
    .text(`${group}:`);
  legendX += 48;
  for (const s of sources.filter((s) => s.group === group)) {
    legend.append("rect").attr("x", legendX).attr("width", 12).attr("height", 12).attr("fill", s.color);
    legend.append("text").attr("x", legendX + 17).attr("y", 10).text(s.name);
    legendX += 30 + s.name.length * 6.5;
  }
  legendX += 20;
}

const x = d3.scaleLinear()
  .domain([first.year, last.year])
  .range([0, dims.chartWidth]);

const charts = [
  {key: "share", title: "Share of Generation (%)", yMax: 100, format: (v) => `${v.toFixed(1)}%`},
  {key: "twh", title: "Generation (TWh)", yMax: d3.max(mix, (d) => d.total), format: (v) => `${d3.format(",.0f")(v)} TWh`}
];

const cursors = [];

charts.forEach((chart, i) => {
  const left = dims.marginLeft + i * (dims.chartWidth + dims.gap);
  const g = svg.append("g").attr("transform", `translate(${left}, ${dims.marginTop})`);

  const y = d3.scaleLinear()
    .domain([0, chart.yMax])
    .nice()
    .range([dims.chartHeight, 0]);

  g.append("text")
    .attr("x", 0)
    .attr("y", -14)
    .attr("font-size", 13)
    .attr("font-weight", 500)
    .text(chart.title);

  // Horizontal Gridlines
  g.append("g")
    .selectAll("line")
    .data(y.ticks(5))
    .join("line")
    .attr("x1", 0)
    .attr("x2", dims.chartWidth)
    .attr("y1", (d) => y(d))
    .attr("y2", (d) => y(d))
    .attr("stroke", "currentColor")
    .attr("stroke-opacity", 0.1);

  // Stacked Layers (Straight Segments Between Years, no Smoothing)
  const stacked = d3.stack()
    .keys(sources.map((s) => `${s.name} ${chart.key}`))(mix);

  const area = d3.area()
    .x((d) => x(d.data.year))
    .y0((d) => y(d[0]))
    .y1((d) => y(d[1]));

  g.append("g")
    .selectAll("path")
    .data(stacked)
    .join("path")
    .attr("fill", (d, j) => sources[j].color)
    .attr("d", area);

  // Dark Line on Top of the Fossil Layers (the Fossil Total)
  const fossilTop = stacked[2];
  g.append("path")
    .datum(fossilTop)
    .attr("fill", "none")
    .attr("stroke", "#333")
    .attr("stroke-width", 1.5)
    .attr("d", d3.line().x((d) => x(d.data.year)).y((d) => y(d[1])));

  // Label the Fossil Total at Both Ends
  const fossilValue = (d) => (chart.key === "share" ? d.fossilShare : d.fossilTwh);
  [[first, "start"], [last, "end"]].forEach(([d, anchor]) => {
    g.append("text")
      .attr("x", x(d.year) + (anchor === "start" ? 4 : -4))
      .attr("y", y(fossilValue(d)) - 6)
      .attr("text-anchor", anchor)
      .attr("font-weight", 600)
      .attr("paint-order", "stroke")
      .attr("stroke", "white")
      .attr("stroke-width", 3)
      .text(`Fossil ${chart.format(fossilValue(d))}`);
  });

  // Axes
  g.append("g")
    .attr("transform", `translate(0, ${dims.chartHeight})`)
    .call(d3.axisBottom(x).tickValues(d3.range(first.year, last.year + 1, 4)).tickFormat(d3.format("d")));

  g.append("g")
    .call(d3.axisLeft(y).ticks(5).tickFormat(chart.key === "share" ? (v) => v : d3.format(",")));

  g.append("text")
    .attr("x", dims.chartWidth / 2)
    .attr("y", dims.chartHeight + 38)
    .attr("text-anchor", "middle")
    .text("Year");

  // Cursor Line (Hidden Until the Mouse Moves over a Chart)
  const cursor = g.append("line")
    .attr("y1", 0)
    .attr("y2", dims.chartHeight)
    .attr("stroke", "#333")
    .attr("stroke-dasharray", "4 3")
    .attr("display", "none");
  cursors.push(cursor);

  // Transparent Overlay that Captures the Mouse
  g.append("rect")
    .attr("width", dims.chartWidth)
    .attr("height", dims.chartHeight)
    .attr("fill", "transparent")
    .on("mousemove", (event) => showYear(Math.round(x.invert(d3.pointer(event)[0])), left + d3.pointer(event)[0]))
    .on("mouseleave", hideYear);
});

// Tooltip Listing Every Source's Share and Output for the Hovered Year
const tooltip = svg.append("g").attr("display", "none").attr("pointer-events", "none");
const tooltipBox = tooltip.append("rect")
  .attr("fill", "white")
  .attr("stroke", "#999")
  .attr("rx", 4);
const tooltipText = tooltip.append("text");

function showYear(year, mouseX) {
  const d = mix.find((r) => r.year === Math.max(first.year, Math.min(last.year, year)));
  cursors.forEach((c) => c.attr("x1", x(d.year)).attr("x2", x(d.year)).attr("display", null));

  const lines = [
    {text: `${d.year}: Total ${d3.format(",.0f")(d.total)} TWh`, bold: true},
    ...sources.slice().reverse().map((s) => ({text: `${s.name}: ${d[`${s.name} share`].toFixed(1)}% · ${d3.format(",.0f")(d[`${s.name} twh`])} TWh`})),
    {text: `Fossil: ${d.fossilShare.toFixed(1)}% · ${d3.format(",.0f")(d.fossilTwh)} TWh`, bold: true},
    {text: `Clean: ${d.cleanShare.toFixed(1)}% · ${d3.format(",.0f")(d.cleanTwh)} TWh`, bold: true}
  ];

  tooltipText.selectAll("tspan")
    .data(lines)
    .join("tspan")
    .attr("x", 8)
    .attr("dy", (l, j) => (j === 0 ? 16 : 14))
    .attr("font-weight", (l) => (l.bold ? 600 : null))
    .text((l) => l.text);

  const box = tooltipText.node().getBBox();
  tooltipBox.attr("width", box.width + 16).attr("height", box.height + 12);
  const boxWidth = box.width + 16;
  const tx = mouseX + 12 + boxWidth > totalWidth ? mouseX - 12 - boxWidth : mouseX + 12;
  tooltip.attr("transform", `translate(${tx}, ${dims.marginTop + 4})`).attr("display", null);
}

function hideYear() {
  cursors.forEach((c) => c.attr("display", "none"));
  tooltip.attr("display", "none");
}

panel.setChart(svg.node());
```

## What the Charts Show

The clean share of world generation rose from ${first.cleanShare.toFixed(1)}% in ${first.year} to ${last.cleanShare.toFixed(1)}% in ${last.year}, so the fossil share fell from ${first.fossilShare.toFixed(1)}% to ${last.fossilShare.toFixed(1)}% (left).
Over the same years, total generation grew from ${d3.format(",.0f")(first.total)} TWh to ${d3.format(",.0f")(last.total)} TWh, and fossil generation grew from ${d3.format(",.0f")(first.fossilTwh)} TWh to ${d3.format(",.0f")(last.fossilTwh)} TWh (right).
A falling fossil share and a rising fossil amount happened at the same time: total generation grew fast enough that a smaller share of it was still more electricity.
