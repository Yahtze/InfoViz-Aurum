# Q3: Largest Changes in the Share of Electricity Generation from Clean Sources and How They Unfolded, 2000–2024

<div class="question">
<span class="question-label">Guiding Question</span>

Which countries gained or lost the most clean electricity share between 2000 and 2024, and how did that change unfold over the years?

</div>

Only the 108 countries with endpoint data and at least 10 TWh of generation in 2024 are compared.

## The Short Answer

Of the 108 compared countries, ${q3Facts.up} raised their clean share between 2000 and 2024 and ${q3Facts.down} lowered it. The biggest gain was ${q3Facts.best.country}, up ${q3Facts.best.pp} points from ${q3Facts.best.from}% to ${q3Facts.best.to}%, and the biggest loss was ${q3Facts.worst.country}, down ${q3Facts.worst.pp} points from ${q3Facts.worst.from}% to ${q3Facts.worst.to}%.

## How to Read This Page

The three plots follow one thread, from how much a share changed to where it started to when the change happened.

1. **[How Much Did Shares Change?](#largest-increases-and-decreases)** Ranked bars show the size of each change, for the biggest gains and the biggest losses on one shared scale.
2. **[Where Did Each Country Start?](#clean-shares-at-start-and-end)** The dumbbells show the starting and ending levels behind each change, because the same gain can mean very different things from a low or a high start.
3. **[When Did It Happen?](#clean-share-over-time)** The lines show the path between the two endpoints. Start with the default selection, then pick countries from the first two plots.

Each plot has a collapsible **Specific Interactions** note just above it; open it for how to use that plot's controls.

```js
// Facts Quoted in the Page Text, Computed from the Data so the Numbers Cannot Drift from the Charts
const q3Facts = (() => {
  const ranked = comparison.slice().sort((a, b) => d3.descending(a.d_clean_share_pp, b.d_clean_share_pp) || d3.ascending(a.country, b.country));
  const describe = (d) => ({country: d.country, pp: Math.abs(d.d_clean_share_pp).toFixed(1), from: d.clean_share_pct_2000.toFixed(1), to: d.clean_share_pct_2024.toFixed(1)});
  return {
    up: comparison.filter((d) => d.d_clean_share_pp > 0).length,
    down: comparison.filter((d) => d.d_clean_share_pp < 0).length,
    best: describe(ranked[0]),
    worst: describe(ranked.filter((d) => d.d_clean_share_pp < 0).at(-1))
  };
})();

// Pick the Largest Increases and Decreases (Only Positive Gains and Negative Losses Appear)
function pickTails(n) {
  const increases = comparison
    .filter((d) => d.d_clean_share_pp > 0)
    .sort((a, b) => d3.descending(a.d_clean_share_pp, b.d_clean_share_pp) || d3.ascending(a.country, b.country))
    .slice(0, n);

  const decreases = comparison
    .filter((d) => d.d_clean_share_pp < 0)
    .sort((a, b) => d3.ascending(a.d_clean_share_pp, b.d_clean_share_pp) || d3.ascending(a.country, b.country))
    .slice(0, n);

  return {increases, decreases};
}

## Clean Shares at Start and End

<p class="bridge">The bars gave the size of each change but not the starting point, which decides what the change means.</p>

This plot revisits the same countries and shows where each one started in 2000 and where it ended in 2024, not only how far it moved. It matters for the guiding question because the same change means very different things from a low start and from a high one.

**How to Read It:** An open circle marks a country's 2000 share and a filled diamond its 2024 share, on a shared 0–100% axis. The line between them is the size and direction of the change.

**Watch Out For:** The line joins two endpoints and does not show the years between them, so a country could have risen steadily, jumped, or dipped and recovered along the way; the line chart below shows which. The size of a change is read from the length of a thin line, which is less precise than the bar lengths above, so use the bars or the hover tooltip for exact values. Only the same largest gainers and losers appear, so the plot says nothing about countries with smaller changes.

## Clean Share Over Time

<p class="bridge">The endpoints leave out the years between them, so this plot shows when the change happened.</p>

These lines trace the clean share of the countries you choose in every year from 2000 to 2024, starting with the largest gainers and losers. They answer the second half of the guiding question, how the change unfolded, by showing whether it was steady, sudden, or reversed.

    .attr("class", "trend-country highlightable")
    .attr("data-country", (d) => d)
    .on("mouseenter", (event, d) => trendHighlight(d))
    .on("mouseleave", () => trendHighlight(null));

  countryGroups.append("path")
    .attr("fill", "none")
    .attr("stroke", (d) => trendColor(d))
    .attr("stroke-width", 2.25)
    .attr("stroke-linejoin", "round")
    .attr("d", (d) => trendLine(trendSeries.get(d)));

  // Wide Invisible Path so Thin Lines are Easy to Hover
  countryGroups.append("path")
    .attr("fill", "none")
    .attr("stroke", "transparent")
    .attr("stroke-width", 12)
    .attr("d", (d) => trendLine(trendSeries.get(d)))
    .append("title")
    .text((d) => d);

  // One Point per Year with its Value on Hover
  countryGroups.selectAll("circle")
    .data((name) => trendSeries.get(name).filter((d) => d.share != null).map((d) => ({...d, name})))
    .join("circle")
    .attr("cx", (d) => trendX(d.year))
    .attr("cy", (d) => trendY(d.share))
    .attr("r", 2.5)
    .attr("fill", (d) => trendColor(d.name))
    .append("title")
    .text((d) => `${d.name}, ${d.year}\nClean Share: ${pct(d.share)}%`);

  countryGroups.append("text")
    .attr("x", trendDims.width + 8)
    .attr("y", (d) => labelY.get(d) ?? 0)
    .attr("dy", "0.35em")
    .attr("fill", (d) => trendColor(d))
    .attr("font-weight", 600)
    .text((d) => d);
}

trendPanel.setChart(trendSvg.node());
```

## Comparison of the Visualizations

| | Largest Increases and Decreases | Clean Shares at Start and End | Clean Share Over Time |
|---|---|---|---|
| **Shows** | The size of each change, as a bar length | Where each country started and ended, and the change between them | The clean share of every year from 2000 to 2024 for countries you choose |
| **Strengths** | The size of a change is the easiest thing to read, and bars from both panels can be compared directly on one scale. | The starting and ending levels are visible, so a country that moved from 5% to 35% is distinguishable from one that moved from 60% to 90%. | The path between the endpoints is visible: when the change happened, whether it was steady or sudden, and whether it reversed. |
| **Weaknesses** | Two countries with the same change look identical, even when one started near zero and the other was already high. The final level is not shown. | The line joins two endpoints, so everything in between is hidden. Size of change is read from a thin line, which is harder to compare than bar length. | Lines overlap and become hard to follow when many countries are selected, and the change itself is not shown as a single number. |
| **Best For** | Ranking countries by how much they changed | Judging how far each country got, and from where | Understanding how and when particular countries changed |
